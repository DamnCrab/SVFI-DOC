设置页的任务列表提供两种播放器：**外部播放器**与**内置播放器**。右键某一任务即可打开；内置播放器也可以用列表下方的 **播放器开启** 开关进入。

二者用途不同：外部播放器按当前软件设置，用自带的 mpv **实时**预览超分或补帧效果；内置播放器只回放原片，用来画蒙版、划分区间、确认转场和标定入出点，**不能**做实时超补预览。

不要与左侧栏的[预览](/zh/pages/sidebar/#预览)页、以及[任意窗口实时播放](/zh/pages/realtime-window/)混淆。预览页看的是任务输出过程；实时超补是对任意窗口做覆盖层缩放。

## 外部播放器

在任务上右键，选择 **开启外部播放器**。软件会根据该任务当前的补帧、超分、目标帧率、所用 GPU 等设置，拉起自带的 **mpv**，对片源做实时处理后播放。

启动时会询问是否启用补帧：选是则按当前补帧模型与输出帧率插帧；选否则只按超分等其余设置播放。

::: warning
实时超分预览仅支持 **TensorRT** 超分模型。若已开启超分但当前模型不是 TensorRT 路径，外部播放器会启动失败。
:::

外部播放器只用于确认观感，不会写出成片。正式导出仍需在设置页点击一键补帧或一键压制。

## 内置播放器

在任务上右键选择 **开启内部播放器来切分任务段**，或打开 **播放器开启**。任务列表会被片源预览条替换。

时间轴右侧有三种模式：**正常**、**多区间任务**、**转场确认**。左侧画笔进入静态蒙版；右侧两个箭头按钮分别设置整段任务的入点和出点。

### 绘制静态蒙版

点击播放条左侧画笔，进入蒙版画布。可用画笔或矩形圈出需要保护或修复的区域，保存后蒙版会绑定到当前任务。

常见用途：

- **游戏视频 UI**：补帧时蒙版区域内保留原图像素，血条、准星、小地图等静止界面不会被光流拉变形。
- **去水印**：配合 [InPaint 去水印模型](/zh/pages/restore-models/#inpaint-去水印模型)，圈出静态水印；模型只在蒙版内识别并修复。请保证蒙版内仍有足够的动态内容，纯色或完全静止的背景去水印效果较差。

画完请保存。使用 InPaint 却未保存蒙版时，任务会无法开始。蒙版画布的撤销 / 重做见[其他进阶说明](/zh/pages/other-advanced-settings/#蒙版绘制页面)。

### 划分多任务区间

切到 **多区间任务**。在时间轴上右键 **在此处添加任务区间帧**，视频会被分成多段彩色区间。点击某一段即可切换，右侧设置会换成该段的配置。

**默认使用第一段区间的设置。** 后续段可以单独改补帧模型、超分、帧率等，适合片源里风格或需求明显不同的部分（例如 OP/ED 与正片、过场与过场之间）。

- 拖动关键帧可调整分界；右键可 **删除最近的关键帧** 或编辑关键帧位置。
- 若片源带章节标记，可在播放器区域右键 **将视频章节作为分割**。
- 关闭播放器后会回到第一段，避免后续段把基础设置锁住。
- 仅可播放的视频文件支持多区间。

### 转场检测结果确认

切到 **转场确认**。时间轴上的标记来自转场 JSON（软件离线检测或 Transition Chooser 导出）。在时间轴上右键，可将当前帧标为转场，或删除已有转场点。

建议先关闭自动转场识别、执行一次离线检测，再在此微调。完整步骤见[转场识别设置说明](/zh/pages/scene-detect/#手动选择转场支持)。

### 划分入点与出点

将播放头移到目标位置，点击入点或出点按钮，会写入[任务基本设置](/zh/pages/task-basic/#起始补帧时刻和结束补帧时刻)中的起始 / 结束时刻。软件只处理该区间内的内容，区间外不导出。

也可在基本设置里用 `小时:分钟:秒` 手动填写。指定入出点后，中途终止或断电可能导致进度恢复失败。
